How EXAMFORGE works

A simple workflow for building practice papers.

1. Add your details

Choose class, subject, difficulty and exam duration. Enter one or more topics.

2. Choose question formats

Set the number of MCQs, short answers, long answers and fill-in-the-blanks.

3. Generate and review

The local question builder makes editable draft questions from topic-based templates. It does not use an AI service or internet connection.

4. Print or save

Use Print / Save PDF to save a clean copy. Review every question and answer hint before distributing.
